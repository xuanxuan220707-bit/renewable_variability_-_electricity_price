# renewable_variability_-_electricity_price
This project analyzes hourly electricity demand, onshore wind and solar generation, weather, and reported actual prices in Spain from 2015 to 2018. Specifically, I compare six-hour-ahead high-price warnings with baselines based on historical prices. I use residual load to describe the demand remaining for other generation, storage, and imports; the dataset does not measure unmet demand.

# Dataset

I use Kaggle’s Hourly energy demand generation and weather dataset, released under CC0. Its source documentation attributes electricity data to ENTSO-E and weather observations for five Spanish cities to OpenWeather. I document data provenance, verification, and licensing information and incorporate notebook-generated figures into the report. The project code is licensed under MIT.
